# World map for the Network page

`internal/web/static/world.json` is generated by `make_world.py` from Natural Earth 1:110m
Admin 0 countries (public domain), as packaged in world-atlas 2.0.2 (`countries-110m.json`, ISC
licence): the TopoJSON arcs are decoded, rings that cross the antimeridian are split, every
point is projected with the Equal Earth projection onto a 1000-unit-wide canvas and each
country becomes one SVG path, keyed by its ISO 3166-1 alpha-2 code (pycountry maps the numeric
ids). Antarctica is left out.

    pip install pycountry
    python make_world.py countries-110m.json ../../internal/web/static/world.json

The output is `{"source", "license", "w", "h", "countries": [{"id", "n", "d"}]}`. world-atlas's ISC
licence asks for its copyright and permission notice in every copy: `license` carries it, so the
program that embeds the map carries it too; `THIRD_PARTY_NOTICES.md` at the top of the repository
has it as well.
